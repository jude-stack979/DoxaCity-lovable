# Doxa City Vision

# Website Creation Prompt — Premium Christian Clothing Brand

Create a **modern, premium e-commerce website for a Christian clothing brand** called **DOXA CITY**.

The website should feel like a **high-end contemporary Christian fashion brand**, combining **luxury minimalism, modern streetwear, and Christian identity**. The design should be clean, sophisticated, editorial, and mobile-friendly.

## 1. Main Purpose

The website should allow me to:

* Display my T-shirt designs professionally.

* Upload/add new products easily.

* Show product images, names, descriptions, prices, available sizes, and colours.

* Allow customers to select a product, size, colour, and quantity.

* Add multiple products to a shopping cart.

* Review their cart before ordering.

* Send the complete order directly to my **WhatsApp** for confirmation and payment arrangements.

This is primarily a **catalogue + shopping cart + WhatsApp ordering website**, rather than a traditional online payment store.

# 7. WhatsApp Ordering System

This is a critical feature.

**Order Details:**

1. REDEEMED TEE

   Size: XL

   Colour: Black

   Quantity: 2

2. BUILT FOR HIS GLORY TEE

   Colour: Cream

   Quantity: 1

   Price: ₵350

The website should open WhatsApp with this message already prepared.

Use my WhatsApp number as a configurable setting rather than hard-coding it into multiple places.

The website should look like a **premium fashion label**, not a generic church website.

Use:

* Minimalist layouts

* Large editorial photography

* Strong typography

* Generous whitespace

* High-quality product photography

* Subtle animations

* Clean product grids

* Sophisticated hover effects

* Smooth page transitions

**Luxury × Streetwear × Christianity × African Contemporary Fashion**

* Black

* Off-white

* Cream

* Charcoal

* Soft grey

Typography should be modern, elegant, and highly readable.

The website must be **fully responsive**.

The mobile version should feel intentionally designed rather than simply shrinking the desktop version.

* Easy size selection

* Sticky cart access

* Fast WhatsApp ordering

* Easy navigation

* Large readable text

The WhatsApp ordering button should be particularly easy to access on mobile.

# 18. Important Technical Requirements

Build the website with a clean, scalable structure.

The product system should be designed so that I can add dozens of T-shirts later without redesigning the website.

Use reusable product cards and product-detail components.

Prices should use **Ghanaian Cedi (₵)**.

The website should be optimized for:

* Fast loading

* Mobile responsiveness

* SEO

* Accessibility

* High-quality image presentation

* Simple navigation

Do not implement unnecessary payment gateways at this stage.

The primary conversion action should be:

**ADD TO CART → REVIEW ORDER → ORDER VIA WHATSAPP**

Make the shopping experience extremely simple and frictionless.

---

# FINAL CREATIVE DIRECTION

The final website should feel like a **real premium Christian fashion brand**, not an ordinary clothing catalogue.

Think:

**Minimal.

Bold.

Premium.

Contemporary.

Faith-driven.

African.

Fashion-forward.**

The T-shirts and their messages should always be the visual focus.

Create the website with **realistic placeholder products and images initially**, but structure everything so I can easily replace them with my actual DOXA CITY T-shirt designs, prices, descriptions, and product photography later.
